# Step 3. 제목과 목차 프롬프트

Step 2 답변 바로 다음에, 아래에서 `[ ]` 부분만 바꿔서 붙여넣으세요.

```
타깃 키워드: [순천 닭볶음탕 밀키트]
서브 키워드: [닭볶음탕 밀키트 추천, 국내산 닭 밀키트, 순천 맛집]
목적: 네이버 블로그 정보형 글 (우리 밀키트를 자연스럽게 소개)
독자: [집에서 간편하게 닭볶음탕 해먹고 싶은 30~40대 주부/자취생]

요청:
1. 클릭률 높은 제목 5개 (메인 키워드를 제목 앞쪽에, 30자 이내, 과장 표현 금지)
2. 이 키워드로 검색하는 사람의 검색의도 3줄 요약
3. H2/H3 구조 목차 (소제목 4~6개, 각 소제목 아래 다룰 핵심 1줄)
   - 마지막엔 매장/구매 정보와 FAQ 자리 포함
```

## 다른 주제 예시 (키워드만 바꿔 쓰기)
- `순천 회식장소` → 독자: 순천 직장인 회식 담당자 / 단체석 100인·주차 강조
- `찜닭 밀키트` → 독자: 아이 있는 가족 / 단짠 기본맛·매콤 선택 강조
- `순천 핫도그` / `순천 여행 먹거리` → 독자: 순천만 여행객 / 미나리 로컬 재료 강조
