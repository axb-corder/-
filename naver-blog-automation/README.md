# 클로드로 네이버 블로그 글쓰기 자동화 — 닭잡고오리발 순천본점용

인스타 게시물(marketer_c_, 8장 카드)의 6단계 방법을 **실제로 돌아가는지 확인**하고,
우리 가게(닭잡고오리발 순천본점)에 맞춰 **복사해서 바로 쓸 수 있게** 만든 세트입니다.

## 1. 실행 가능 여부 확인 결과

| 단계 | 게시물 내용 | 가능 여부 | 비고 |
|---|---|---|---|
| Step 1 | 클로드 프로젝트 만들기 | ✅ 가능 | claude.ai → Projects → New project. 지침(Instructions)과 파일 업로드 기능이 실제로 있음 |
| Step 2 | 데이터랩·키워드도구로 자료 모으기 | ✅ 가능 (사람이 직접) | 네이버 데이터랩은 무료·로그인 불필요. 검색광고 키워드도구는 **검색광고 계정(무료) 가입 필요**. 클로드가 네이버 데이터를 직접 조회하진 못하므로 **화면 캡처나 엑셀을 업로드**하는 방식 |
| Step 3 | 제목·목차 프롬프트 | ✅ 가능 | 그대로 동작 |
| Step 4 | 본문 초안 자동 작성 | ✅ 가능 | 그대로 동작 |
| Step 5 | 내 경험 톤으로 다듬기 | ✅ 가능 | **가장 중요한 단계.** AI 티 나는 글은 네이버 저품질 위험이 있어 내 경험·실제 사진이 꼭 들어가야 함 |
| Step 6 | 네이버 블로그 편집기에 업로드 | ⚠️ 수동만 가능 | 게시물 설명대로 네이버 블로그 글쓰기 오픈 API는 종료되어 **자동 발행은 불가**. 복사-붙여넣기 후 사진·태그 넣고 직접 발행 |

**결론:** "완전 자동"은 아니고 **키워드 조사 → 초안까지 자동, 업로드는 수동**인 반자동 방식이며, 이 범위에서는 문제없이 실행됩니다.

> 참고: 게시물 이미지 속 모델 선택창에 "Claude 3.5 Sonnet"이 보이는데 예전 모델입니다. 지금은 모델 선택창에서 기본(최신) 모델을 그대로 쓰면 됩니다.

## 2. 파일 구성 (단계별로 그대로 복사해서 쓰세요)

| 파일 | 언제 쓰나 |
|---|---|
| `step1_프로젝트_지침.md` | 프로젝트 만들 때 **Instructions(지침)** 칸에 붙여넣기 |
| `step1_가게정보.md` | 프로젝트 **파일(Knowledge)** 에 업로드 |
| `step2_키워드_자료모으기.md` | 데이터랩·키워드도구에서 무엇을 캡처해 올릴지 |
| `step3_제목목차_프롬프트.md` | 채팅창에 붙여넣기 (키워드만 바꿔서) |
| `step4_본문초안_프롬프트.md` | Step 3 답변 다음에 붙여넣기 |
| `step5_경험톤_다듬기_프롬프트.md` | Step 4 답변 다음에 붙여넣기 |
| `step6_업로드_체크리스트.md` | 네이버 블로그에 올리기 전 최종 검수 |

## 3. 한 편 쓰는 순서 (약 20~30분)

1. (처음 한 번만) Step 1 — 프로젝트 `네이버 블로그 자동화` 생성, 지침 붙여넣기, 가게정보 업로드
2. 데이터랩·키워드도구에서 키워드 확인 → 캡처 업로드 (Step 2)
3. 같은 프로젝트 안에서 **새 채팅** 열고 Step 3 → 4 → 5 프롬프트 순서대로
4. 결과를 네이버 블로그 편집기에 붙여넣고 [사진1], [사진2] 자리에 실제 사진 넣기 → 체크리스트 확인 후 발행 (Step 6)
