# Step 2. 키워드와 자료 모으기

클로드는 네이버 검색량을 직접 볼 수 없습니다. **사람이 확인하고 캡처를 올려주는 단계**입니다.

## ① 네이버 데이터랩 — 시즌/트렌드 확인 (무료, 로그인 불필요)
1. https://datalab.naver.com → **검색어트렌드**
2. 주제어에 비교할 키워드 입력 (최대 5개). 예시:
   - `순천 맛집` / `순천 닭볶음탕` / `찜닭 밀키트` / `닭볶음탕 밀키트` / `순천 회식장소`
3. 기간 **1년**, 범위 **전체** → 조회 → 그래프 화면 캡처

## ② 네이버 검색광고 키워드도구 — 세부 키워드 찾기 (검색광고 계정 필요, 가입 무료)
1. https://searchad.naver.com 로그인 → 도구 → **키워드 도구**
2. 키워드 입력 예: `닭볶음탕밀키트`, `순천맛집`, `찜닭밀키트`
3. 결과의 **월간검색수(PC/모바일)**, **월평균클릭수**, **경쟁정도** 표를 캡처하거나 다운로드(엑셀)
4. 고르는 기준: 월간검색수 **1,000~10,000** 사이 + 경쟁정도 **낮음/중간** 키워드가 작은 블로그에 유리

## ③ 상위 글 구조 참고
- 네이버에서 고른 키워드 검색 → 블로그 탭 상위 3개 글의 **소제목 흐름**만 메모 (본문 복사 금지)

## ④ 내 경험 메모·사진
- 이번 글에 넣을 실제 사진 3~6장 (조리 과정, 완성샷, 매장 내부, 포장 상태 등)
- 그 사진과 관련된 짧은 메모 (언제, 누구와, 어떤 반응)

## 클로드에 올리는 법
프로젝트 안에서 새 채팅 → `+` 버튼으로 캡처/엑셀/메모 업로드 후 아래를 붙여넣기:

```
업로드한 데이터랩 그래프와 키워드도구 표를 보고 정리해줘.
1. 지금 시기에 검색이 오르는 키워드
2. 메인 키워드 1개 추천 (검색수 1,000~10,000, 경쟁 낮음/중간 우선)과 이유
3. 같이 쓸 서브 키워드 3개
4. 상위 글 소제목 흐름에서 공통으로 다루는 내용 / 빠져 있어서 우리가 차별화할 수 있는 내용
```
