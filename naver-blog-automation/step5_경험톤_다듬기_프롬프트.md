# Step 5. 내 경험 톤으로 다듬기

AI가 쓴 티가 나는 글은 네이버에서 노출이 약해질 수 있습니다. **이 단계를 건너뛰지 마세요.**

## 먼저 할 일
채팅창에 실제 사진(또는 사진 설명)과 짧은 경험 메모를 올립니다. 예시:
```
내 경험 메모:
- 지난주 토요일 단체 예약 40명, 닭볶음탕 화끈매운맛 주문 많았음
- 밀키트 처음 만들 때 당면이 불어서 따로 포장하게 됨
- 손님이 "집에서 해도 가게 맛 그대로"라고 후기 남겨줌
사진: 1) 밀키트 포장 상태 2) 냄비에 끓이는 장면 3) 완성 접시 4) 매장 단체석
```

## 붙여넣을 프롬프트
```
초안을 1인칭 후기형 말투로 수정해줘. (사장님이 직접 쓰는 글)
- [사진1], [사진2] 위치 표시를 넣고, 내가 올린 사진 순서에 맞춰 배치해줘
- 내 경험 메모 내용을 자연스럽게 녹여주고, 내 경험이 더 들어가면 좋을 자리는 (여기에 경험 한 줄) 로 빈칸을 남겨줘
- 문단은 짧게 나눠서 읽기 쉽게 정리해줘
- "~합니다"만 반복하지 말고 "~했어요", "~더라고요"를 섞어줘
- 메인 키워드 횟수와 가게정보 사실은 그대로 유지
```

## 마지막 다듬기 (필요할 때만)
```
- AI가 쓴 것 같은 표현(예: "~에 대해 알아보겠습니다", "결론적으로", "다양한")을 찾아서 사람 말투로 바꿔줘
- 제목 1개 + 본문 + 해시태그 10개를 네이버 블로그에 바로 붙여넣을 형태로 최종본만 다시 줘
```
