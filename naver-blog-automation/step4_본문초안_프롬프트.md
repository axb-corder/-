# Step 4. 본문 초안 자동 작성

Step 3 답변에서 마음에 드는 제목 번호를 골라 아래를 붙여넣으세요.

```
[제목 2번]으로 정하고, 위 목차 기준으로 네이버 블로그 초안을 작성해줘.
- 서론-본론-정리 구조로 쓰고
- 소제목마다 핵심 포인트를 넣어줘
- 과장 없는 정보형 톤으로, FAQ 3개 포함
- 가격·조리법·보관법·원산지는 프로젝트 파일 '가게정보' 내용 그대로 써줘
- 공백 포함 1,500~2,500자
- 마지막에 매장 정보 요약 + 댓글 유도 질문 한 줄
```

## 결과 확인 포인트
- [ ] 제목/서론/본문/정리/FAQ가 다 있는가
- [ ] 가격·주소·영업시간이 가게정보와 똑같은가 ([확인 필요] 표시가 있으면 직접 채우기)
- [ ] 메인 키워드가 5~7회 들어갔는가 (부족하면 "메인 키워드 횟수 세서 6회로 맞춰줘")
