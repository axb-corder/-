# Step 6. 네이버 블로그 편집기에 업로드

네이버 블로그 글쓰기 오픈 API는 종료되어 **자동 발행은 안 됩니다.** 최종 검수 후 직접 올리는 방식이 가장 안전합니다.

## 올리는 순서
1. 네이버 블로그 → **글쓰기** (스마트에디터 ONE)
2. **제목** 입력칸에 제목 붙여넣기
3. **본문** 붙여넣기 → 붙여넣기 후 서식이 깨지면 "텍스트만 붙여넣기"(Ctrl+Shift+V)
4. [사진1], [사진2] 글자를 지우고 그 자리에 실제 사진 삽입 (사진 대표 설명에 키워드 1회)
5. 매장 위치는 에디터의 **장소** 버튼으로 `닭잡고오리발 순천본점` 지도 첨부
6. 하단 **태그**에 해시태그 입력
7. 아래 체크리스트 확인 후 **발행**

## 발행 전 체크리스트
- [ ] 제목에 메인 키워드가 앞쪽에 들어갔다
- [ ] 가격·영업시간·주소·전화번호가 지금 실제와 같다 (할인가 변동 확인!)
- [ ] [사진N], (여기에 경험 한 줄) 같은 빈칸 표시가 남아있지 않다
- [ ] 실제로 찍은 사진이 3장 이상 들어갔다 (AI 이미지·남의 사진 X)
- [ ] "최고/1등/무조건" 같은 과장·단정 표현이 없다
- [ ] 다른 블로그 글을 그대로 옮긴 문장이 없다
- [ ] 스마트스토어·카카오톡 링크가 정상 동작한다
- [ ] 글 마지막에 댓글 유도 질문이 있다

## 운영 팁
- 하루 1편, 같은 시간대에 꾸준히. 같은 날 여러 편 몰아서 발행하지 않기
- 같은 키워드로 비슷한 글을 반복하지 말고 Step 3의 다른 주제 예시로 돌려쓰기
- 발행 후 2~3일 뒤 네이버에서 키워드 검색해 노출 확인 → 잘 된 글의 키워드를 프로젝트 파일 '가게정보'의 메모에 기록
