# ✈️ 순천시 플라이오버

블록 건물·도로·나무로 만든 **미니어처 순천시** 위를 카메라가 곡선을 그리며 나는 30초 영상입니다. Three.js로 장면을 만들고, 헤드리스 Chromium으로 프레임을 찍어 ffmpeg로 MP4를 만듭니다.

- 길이·크기: 30초 · 1920×1080 · 30fps
- 결과물: `suncheon-flyover.mp4`
- t=30초 화면이 t=0초와 똑같아서, 이어 붙이면 끊김 없이 한 바퀴 돕니다.

## 장면
| 시간 | 내용 |
|---|---|
| 처음~끝 | 왼쪽 위에 짙은 알약 제목(비행기 + 순천시) |
| 0~1.5초 | 높은 곳에서 도시 전체를 비스듬히 내려다봄 (뒤쪽 강·다리, 앞쪽 철길) |
| 1.5~11.8초 | 낮게 내려와 첫째 명소 **순천오천그린광장**(파랑) 곁을 지남 |
| 7.9~19.7초 | 도시 한가운데 **순천만국가정원**(보라) |
| 15.2~27.4초 | 오른쪽 안쪽 **순천만습지**(주황) → 다시 솟아오름 |
| 27.4~30초 | 처음 자리로 돌아오며 따뜻한 햇빛이 도시를 한 번 훑고 지나감 |

명소 모양은 실제 건물을 흉내 내지 않고 미니어처 세트용으로 새로 만들었습니다.
- 그린광장: 둥근 잔디 광장, 흰 고리 지붕, 파란 첨탑
- 국가정원: 꽃 두른 계단식 정원 언덕, 보라 돔 정자
- 습지: 갈대밭, 나무 데크길, 주황 지붕 전망대

## 사용법
```bash
cd suncheon-flyover
npm install

npm run serve                 # 브라우저 미리보기 → http://localhost:5173
npm run render                # suncheon-flyover.mp4 만들기 (ffmpeg 필요)
node render.js out.mp4 --stills 0,8,14.4,21   # 특정 시각의 장면만 PNG로 저장
```
`render.js`는 `playwright` 패키지를 사용합니다. 없으면 `npm i -D playwright`로 설치하세요.

## 고치는 곳 (`scene.js`)
- `LANDMARKS`: 명소 이름·색·위치
- `CAM_KEYS`: 카메라 경로(시각·위치·바라보는 점)
- `TAG_TIMES`: 이름표가 뜨고 사라지는 시각
- `PASTELS`: 건물 색
