# 홈피드 블로그 자동화 (Claude 8역할)

네이버 **홈피드(네이버 앱 메인 피드)**에 올라갈 만한 블로그 글을
키워드 조사 → 제목 → 목차 → 본문 → 점검 → 사진 → 통계 분석까지 단계별로 만드는 도구입니다.

## 열기

```bash
npm install
npm run dev
# → http://localhost:3000/blog-studio.html
```

배포 후에는 `https://<사이트주소>/blog-studio.html` (매장 홈페이지 메뉴에는 노출되지 않고, 검색엔진 수집도 막아둠).

## 사용 순서

| 단계 | 탭 | 하는 일 |
|---|---|---|
| 0 | 프로젝트 지침 | Claude 프로젝트 만들고 [PROJECT_INSTRUCTIONS.md](./PROJECT_INSTRUCTIONS.md) 를 지침에 붙여넣기 (최초 1회) |
| 1 | Niche Strategist | 홈피드 카테고리 + 매출로 이어지는 주제 고르기 |
| 2 | Keyword Researcher | 경험형·반전형·비교형·시즌형·질문형 글감 100개 |
| 3 | Title Writer | 피드에서 멈추게 하는 제목 10개 + 썸네일 문구 |
| 4 | Outline Builder | 도입부 4단계 + 문장형 소제목 3개 목차 |
| 5 | Post Writer | 내 경험 메모를 녹인 1000~1400자 본문 |
| 6 | SEO Checker | **초안 붙여넣으면 브라우저에서 바로 자동 채점** + Claude 검수 프롬프트 |
| 7 | Image Planner | 대표사진(썸네일) 구도, [사진N]별 촬영 가이드 |
| 8 | Growth Analyst | 주간 통계 → 잘된 글 공통점, 다음 주 글 3개 |
| ⚡ | 빠른 모드 | 3~5번 + 자체점검을 프롬프트 하나로 |

왼쪽에 키워드·주제·**내 경험 메모**를 채우면 모든 프롬프트에 자동으로 들어갑니다.
입력값은 브라우저(localStorage)에만 저장되고 서버로 전송되지 않습니다.

## 홈피드 자동 점검 항목 (6번)

글자수 1000~1400자 · 키워드 5회 이상(12회 초과 경고) · 한 문장 몰아넣기 · 제목(키워드 앞쪽, 18~32자, 광고 단어) ·
소제목 정확히 3개/문장형(`## `로 표시) · 경험 표현 4회 이상 · 마지막 문장 질문형 · 같은 어미 3연속 ·
긴 문단 · AI 상투어 · 광고성 표현/외부링크 · [사진N] 5개 이상 · 몰입 문장 · 인사말로 시작 여부.
필수 항목이 하나라도 '수정'이면 점수는 79점을 넘지 않습니다.

기준값은 `src/blog-studio/checker.ts` 의 `RULES` 에서 바꿀 수 있습니다.

## 발행

네이버 블로그 글쓰기 오픈 API는 종료되어 자동 발행은 하지 않습니다.
최종본을 편집기에 붙여넣고 [사진N] 자리에 직접 찍은 사진을 넣은 뒤 대표사진·태그를 설정해 발행하세요.
